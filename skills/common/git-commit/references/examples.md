## fix — bug fix

```
fix(sync): fix missing variable not blocking when env-required skill vars are absent

The original logic only output a warning but continued creating symlinks,
causing rendered copies to contain unreplaced {{VAR}} loaded by AI tools.
Changed to immediately return an error and block link creation when missing variables are detected.

Closes #31
```

```
fix(linker): fix race condition when creating symlinks concurrently
```

## refactor — refactoring

```
refactor(registry): split clone and pull logic into separate functions

The original single FetchRegistry() function handled both cases,
making tests hard to isolate. After splitting, each is independently testable.
```

## Common Mistake Comparison

```
Wrong: update code             -> Right: fix(linker): fix symlink target path error
Wrong: changed some stuff      -> Right: refactor(config): extract config reading logic into a standalone function
Wrong: feat: feature done      -> Right: feat(install): implement aic install command core flow
Wrong: fix bug                 -> Right: fix(sync): fix BROKEN state skill rebuild link failure
Wrong: WIP                     -> Right: do not commit WIP; commit the smallest runnable unit
```
