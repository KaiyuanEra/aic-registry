# 调度组命名规范 v1.0

> 适用：自研调度系统中**调度组**的命名（调度实例为数值 ID，不参与命名）。
> 同源规范：《ClickHouse 建表规范 v2.0》《带宽计费业务字段数据字典 v1.0》

---

## 1. 设计原则

1. **全局唯一**：调度组命名在系统范围内唯一，命名即身份。
2. **同频聚合**：一个调度组内任务**并行/顺序执行、共享调度时间**，**禁止混合频率**。
3. **同源建表**：`layer` / `domain` 取值与 ClickHouse 建表规范完全对齐，不引入双轨命名。
4. **主题聚合**：调度组按**业务主题**划分（如带宽采样、账单结算、SLA 监控），每个组内多个实例对应不同目标表。
5. **数据状态分支不入组名**：基于数据状态的条件分支属于实例运行时行为，**不在调度组命名中体现**。

---

## 2. 命名格式

```
{layer}_{domain}_{theme}_{cycle}
```

全部小写 `lower_snake_case`，段间用 `_` 分隔，不允许大写 / 连字符 / 空格。

| 段 | 必选 | 含义 | 来源 / 取值范围 |
|----|------|------|----------------|
| `layer` | ✅ | 目标数据层 | `ods` / `dwd` / `dim` / `dws` / `ads` / `dmp` / `tmp`（同建表规范） |
| `domain` | ✅ | 业务域（业务线 + 子域合并） | 见 §3 |
| `theme` | ✅ | 业务主题（实体 / 处理对象） | 2~6 位英文，如 `sample` / `billing` / `penalty` / `sla` |
| `cycle` | ✅ | 调度频率 | `5min` / `1d` / `1w` / `1mo` |

**示例：**
```
dwd_iaas_bw_sample_5min       带宽采样数据 5 分钟入库
dws_iaas_bw_sample_1d         带宽采样日级聚合
dws_iaas_bill_settle_1d       日级账单结算
ads_iaas_bill_settle_1mo      月度账单出账
dws_iaas_sla_penalty_1d       SLA 扣罚日级判定
ads_iaas_sla_report_1w        SLA 周报表
dwd_paas_log_access_5min      PaaS 访问日志 5 分钟入库
dim_iaas_dev_full_1d          设备全量维度日刷新
```

---

## 3. domain 取值（业务线 + 子域合并）

业务线前缀为 `iaas` / `paas`，子域为 2~4 位英文缩写，二者用 `_` 拼接构成 `domain`。

### IaaS 业务线

| domain | 中文含义 | 适用主题示例 |
|--------|----------|--------------|
| `iaas_dev` | 设备 | 设备主数据、设备状态 |
| `iaas_bw` | 带宽 | 带宽采样、带宽指标 |
| `iaas_bill` | 账单计费 | 计费、出账、对账 |
| `iaas_sla` | SLA / 扣罚 | 扣罚判定、SLA 监控、合规审计 |
| `iaas_res` | 资源 / 合同 | 资源配置、合同信息 |
| `iaas_prv` | 供应商 | 供应商主数据、供应商对账 |

### PaaS 业务线

| domain | 中文含义 |
|--------|----------|
| `paas_log` | 日志 |
| `paas_app` | 应用 |
| `paas_mon` | 监控 |
| `paas_usr` | 用户 |

> 新增 domain 须经数据治理评审；命名规则：`{iaas|paas}_{2~4 位英文}`。

---

## 4. cycle 取值

| cycle | 含义 | 触发时点示例 |
|-------|------|--------------|
| `5min` | 每 5 分钟一次 | `*/5 * * * *` |
| `1d` | 日级（T+1） | 每日固定时点（如 02:00） |
| `1w` | 周级 | 每周固定日（如周一 03:00） |
| `1mo` | 月级 | 每月固定日（不区分月初/月末，由实例参数控制） |

> 月度任务是否在月初或月末执行，由调度组实例运行参数决定，**不进入命名**。

---

## 5. 调度组与建表 cycle 的关系

⚠️ **注意区分两个 `cycle`：**

| 概念 | 含义 | 取值示例 |
|------|------|----------|
| **建表 cycle**（数据周期） | 数据本身的周期属性 | `df` / `di` / `1d` / `7d` / `30d` / `td` / `rt` / `his` |
| **调度 cycle**（调度频率） | 任务执行频率 | `5min` / `1d` / `1w` / `1mo` |

二者不可混用。一个建表 cycle 为 `di`（每日增量）的表，对应的调度 cycle 通常是 `1d`，但也可能是 `5min`（小时内多次增量）。

### 推荐组合（约束性建议）

| 表层级 | 推荐调度 cycle |
|--------|----------------|
| `ods` / `dwd` | `5min` / `1d` |
| `dim` | `1d` / `1w` |
| `dws` | `1d` / `1w` / `1mo` |
| `ads` | `1d` / `1w` / `1mo` |

---

## 6. 调度组划分规则

### 6.1 主题聚合

按"**同一主题 + 同一频率 + 同一目标层**"聚合到一个组。组内实例顺序执行，每个实例对应一张目标表或一段处理逻辑。

**示例：组 `dws_iaas_bw_sample_1d` 包含的实例**

- 实例 0：写入 `dws.dws_bw_sample_p95_1d_local`
- 实例 1：写入 `dws.dws_bw_sample_peak_avg_1d_local`
- 实例 2：写入 `dws.dws_bw_sample_offline_stat_1d_local`

### 6.2 不应放进同一组的情形

| 情形 | 处理 |
|------|------|
| 频率不同（5min + 1d） | **必须**拆为不同组 |
| 目标层不同（dwd + dws） | **必须**拆为不同组 |
| domain 不同（iaas_bw + iaas_bill） | **必须**拆为不同组 |
| 同主题但有强依赖（A → B → C） | 推荐：组内通过实例顺序编号 0/1/2 表达；或拆为多组通过组间依赖串联 |

### 6.3 数据状态分支

基于数据状态走不同子任务（如"采样数据缺失 → 走补采路径"）属于**实例运行时行为**，由实例内部条件判断或多实例共享触发条件实现，**不进入调度组命名**。

## 7. 命名合规校验

| 校验项 | 规则 | 报错提示 |
|--------|------|----------|
| 全局唯一 | 调度组名在系统内唯一 | "调度组名 `{name}` 已存在" |
| 字段段数 | 必须为 4 段 | "调度组名必须包含 layer / domain / theme / cycle 四段" |
| 大小写 | 全小写 lower_snake_case | "命名必须使用 lower_snake_case 格式" |
| layer 合法 | 必须为 7 个固定库之一 | "layer 必须为 ods/dwd/dim/dws/ads/dmp/tmp 之一" |
| domain 合法 | 必须以 `iaas_` 或 `paas_` 起首 | "domain 必须以 iaas_ 或 paas_ 开头" |
| cycle 合法 | 必须为 5min/1d/1w/1mo | "cycle 必须为 5min / 1d / 1w / 1mo 之一" |
| 频率纯净 | 组内所有实例同频 | "调度组内不允许混合频率，请拆分" |
| 主题纯净 | 组内实例 layer / domain / theme 一致 | "调度组内 layer/domain/theme 必须一致" |
| 与建表层级匹配 | 见 §5 推荐组合 | "调度频率与目标层不推荐组合，建议 {推荐值}" |

## 8. 反例

| 反例 | 问题 | 应改为 |
|------|------|--------|
| `bw_sample_5min` | 缺 layer / 业务线 | `dwd_iaas_bw_sample_5min` |
| `dwd_iaas_bandwidth_sample_5min` | domain 子域非缩写 | `dwd_iaas_bw_sample_5min` |
| `Dwd_Iaas_Bw_Sample_5Min` | 含大写 | `dwd_iaas_bw_sample_5min` |
| `dwd-iaas-bw-sample-5min` | 用连字符 | `dwd_iaas_bw_sample_5min` |
| `dwd_iaas_bw_sample_realtime` | cycle 非合法值 | 改用 `5min`，或先扩展规范 |
| `dwd_iaas_bw_sample_5min_prv_aliyun` | 数据状态分支不入组名 | `dwd_iaas_bw_sample_5min`（分支放在实例运行参数） |
| `mixed_iaas_bill_5min_1d` | 混合频率 | 拆分为 `*_5min` 与 `*_1d` 两组 |

---

## 9. 与 ClickHouse 建表规范的字段对照

| 维度 | 建表规范 | 调度组规范 | 关系 |
|------|----------|------------|------|
| 数据层 | `layer`（database） | `layer`（首段） | 取值集合一致 |
| 业务域 | `domain` | `domain` | 调度组的 domain = `{业务线}_{建表 domain}` |
| 实体 | `entity` | `theme` | 调度组按主题，可能聚合多个实体 |
| 周期 | `cycle`（数据周期） | `cycle`（调度频率） | **不同含义**，见 §5 |

---

## 10. 待扩展项

以下场景**当前不在规范内**，如有需要请单独评审后扩展：

- 实时流（`rt`）调度
- 15min / 1h 等其他频率
- 调度组层面的 owner / 团队标识
- 回填（backfill）/ 补数实例的命名标识
- 跨业务线联合调度组
